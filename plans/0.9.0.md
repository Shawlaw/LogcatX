# LogcatX 0.9.0 实施计划

依据：`Others/LogcatX-PRD/LogcatX-0.9.0-PRD.md`（外部 PRD，保持稳定）。
状态跟踪：`plans/0.9.0-status.md`。

## 里程碑拆解（内部管理用，不对外发布中间版本）

- **M0 Baseline & Test Harness**：基线验证全绿；BuildInfo；Fake ADB；CI fmt/clippy/test gate；plans 文档。
- **M1 ADB Core**：`AdbExecutor`（execute / execute_with_timeout / spawn_streaming / cancel / kill / wait / capture / output_limit）；TaskManager skeleton；DeviceDiscovery generation；metadata cache；wireless 进程管理逻辑下沉。
- **M2 Transfer Foundation**：`TransferManager`（TransferTask 模型、队列、进度、取消、retry、并行度控制、多设备隔离）；现有普通文件 push 迁入。
- **M3 Device Files**：Files 一级页面（浏览/排序/多选/快捷路径/收藏）；pull/pull 目录递归；push + Explorer 拖拽；APK 拖拽复用 TransferManager；mkdir/rename/move/delete；RemotePath/RemoteCommandArg 转义抽象；权限区分 UI；run-as 浏览。
- **M4 Updater 2nd Iteration**：DeskFoundry v0.1.6（原子写下沉等）；`check_signed` + 持久化候选离线恢复；Release Notes 内嵌（notesUrl → updates/notes/<ver>.md）；fault isolation；retry/backoff；ACK 改为健康启动后（首帧渲染后）。
- **M5 Reliability Hardening**：cleanup symlink/junction 边界；cleanup race（删前查 active log registry）；wireless 端口扫描分层（深度扫描显式化）；config migration + 原子写；Windows FILEVERSION 数字版本；错误分类（AdbError 等）；多设备压测。
- **M6 RC**：版本一致性校验、artifact smoke test（--version）、CHANGELOG、manual smoke matrix。

## 关键架构决策

| 决策点 | 选择 | 说明 |
| --- | --- | --- |
| Fake ADB 形态 | 独立 bin target `logcatx-fake-adb` + 场景脚本文件驱动 | 进程级替身，AdbExecutor 直接 spawn；`CARGO_BIN_EXE_*` 定位；不进发布 zip |
| adb 路径注入 | `LOGCATX_ADB_PATH` 环境变量 | 测试/CI 注入 fake adb 的统一入口 |
| BuildInfo 来源 | build.rs 生成：`GITHUB_SHA` → `git rev-parse HEAD` → `unknown`；short=7；dirty 仅本地 git 检测 | 不得因获取失败 fail build |
| 目录列举协议 | `adb exec-out` + stat/find 机器可解析输出（不解析 `ls -l` 人类格式） | M3 时定稿具体协议 |
| 远程路径安全 | `RemotePath`/`RemoteCommandArg` 类型化抽象，禁止字符串拼接 shell | M3 |
| DeskFoundry | 升 v0.1.6（需上游开发 + tag，由本 agent 直接 push/tag），原子写优先下沉 | 用户已确认 |
| LogcatX 提交 | master 小步提交，仅本地不 push（push 时机由用户决定） | 用户已确认 |

## 协作约定（来自用户确认 + PRD §51-58）

- 每个 agent 任务输出 PRD §52 要求的八项内容。
- 每轮提交至少 `cargo fmt --check` + `cargo clippy` + 相关单测；核心 ADB/Transfer 改动跑完整 `cargo test`。
- Status 文件记录当前 milestone / 阻塞 / 最后验证 commit，防止重复劳动。
