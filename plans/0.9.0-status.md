## 试用反馈修复·第二轮（2026-09-23，bug 2/3 复发）

- **bug 2 复发根因（实证）**：无窗口 egui 合成输入 harness（`directory_name_double_click_registers_in_ui_harness`）证明双击事件层正常 → 真因在真实设备协议：旧列举脚本依赖 `stat -c '%F	%s	%Y'`，`	` 是字面反斜杠+t（GNU 解释转义、toybox 不一定），`%F` 输出亦随实现漂移 → 真机 kind 解析失败 → 目录不是 `Directory` → 双击永不导航；且真实 `adb shell` pty 输出带 
 污染名称。协议重写为 POSIX `[ -d ]/[ -L ]/[ -f ]` 判型标记 + 空格分隔 `%s %Y` 元数据，解析器剥 
、容忍截断尾。fake adb 集成测试同步新协议，新增 CRLF/截断/空目录哨兵单测。
- **bug 3 复发根因**：第一轮串号路由只对“已作为既有设备传输出现过的串号”生效；幽灵端点（轮换端口，从未见过）永不归并。第二轮：新增 `fold_unresolved_wireless_by_host`——按主机 IP 归并（既有条目 + 同批次内解析成功的传输都提供 host→identity），同主机轮换端点归入同一设备；`start_disconnect` 改为清理该设备全部网络端点（失效端口不再残留）。含单测（同批次归并/异主机隔离/USB 不参与）。
- 测试等待阈值放宽（transfer 5s→10s；上一轮 3s→10s / 5s→15s）：满载并行下 fixture 现场编译挤占计时断言，放宽不削弱“真挂死必失败”的保证。

## 试用反馈修复·第九轮（2026-09-25，bug 20-21：空目录 * 条目 / 右键菜单）

- **bug 20（空目录显示 * 条目）**：真机日志实锤（DCIM/Camera、DCIM/Screenshots 均 "1 entries"）。`for entry in *` 在空目录迭代一次字面 `*`，真机上判型为 `o`（-d/-L/-f 全 false）且个别设备 stat 回退输出非 `- -` 变体，绕过了 `f/o + "- -"` 的哨兵。三层修复：脚本加 `[ -e "$entry" ] || [ -L "$entry" ] || continue`（不存在的 glob 残留直接跳过，空目录输出为空）；解析哨兵放宽为“唯一条目 + 名为 * + stat 行无数字”；空目录 UI 显示“空目录”提示并保留 ../ 行。新增 o/-- 变体单测。
- **bug 21（输入框无右键菜单）**：egui 0.31 TextEdit 只有 Ctrl+C/X/V 无右键菜单。新增 `src/app/text_menu.rs`：`text_edit_menu(response, buf, i18n)` 用 `Response::context_menu` + `TextEdit::load_state/store_state`（游标为字符索引，CJK 按字符→字节边界换算，含单测）实现 剪切/复制/粘贴/全选（粘贴读 arboard 系统剪贴板）。接入全部 19 个输入点（设置 3 + 更新代理 2 + scrcpy 新显示 5 + 清理日期 1 + 别名/参数 2 + 无线 4（经 `normalized_edit` 统一接入）+ 文件页 4）；文件名右键支持 复制文件名/复制完整路径。备注：菜单编辑不走 egui undo 栈（无公开 API），Ctrl+Z 不回退菜单操作。
- i18n 新增 menu.copy/cut/paste/select_all、files.copy_name/copy_full_path（中英）。
