## 架构边界核查（2026-09-26，0.10.0 技术选型确定后）

下一版本 0.10.0 将以 Tauri 2 + Svelte + TypeScript + 系统 WebView2 替换 egui UI；**0.9.0 本身不做 UI 迁移**。按用户增量约束逐项核查，结论：边界已满足，未做重构。

- **Logcat 功能边界**：0.9.0 PRD（2343 行）与代码中均无"UI 实时渲染日志 / 10 万行虚拟滚动 / 实时过滤搜索"类需求——现有范围即"采集落盘 + 采集状态展示 + 历史日志管理 + 应用诊断"。此类能力不属于 0.9.0 或 0.10.0 的既定需求，不得因迁移计划加戏或裁剪现有用户流程。
- **egui 隔离**：`egui/eframe` 引用仅存在于 UI 层——`src/app.rs`、`src/app/*`、`src/ime.rs`、`src/e2e.rs`（feature 门控）、`src/main.rs`（eframe 启动壳）。业务模块 `adb.rs`（含设备发现 `list_devices` + `DeviceMetadataCache` + generation）、`adb_executor.rs`（AdbExecutor）、`task.rs`（TaskManager）、`transfer.rs`（TransferManager）、`remote_fs.rs`、`updater.rs`、`wireless.rs`、`models.rs`、`config.rs`、`fs_utils.rs`、`build_info.rs`、`scrcpy.rs`、`managed_child.rs`、`i18n.rs` 对 egui/eframe 与 `crate::app` 零引用（grep 计数全 0）。
- **状态与事件边界**：设备列表、目录浏览条目、传输进度、错误状态（AdbError/TransferError/RemoteFsError）、更新状态（UpdateCache 持久化候选）均为纯 Rust 数据模型 + mpsc 事件；UI 不承担 ADB 子进程调度、文件传输与状态持久化。
- **版本显示约定（§35）**：侧栏左上角胶囊仅显示 `v{SemVer}`；短 commit ID 仅出现在 Settings 诊断行与更新弹窗当前版本行。
- **未引入 Tauri/WebView2/Svelte/TS/Node**：Cargo.toml/Cargo.lock 与仓库内无任何痕迹；0.9.0 继续用 egui 完成 Files 页、传输队列、更新弹窗、设备管理。

## 试用反馈修复·第十一轮（2026-09-28，preview 包验证 bug 4-7）

- **bug 4/5（菜单动作丢焦点/全选不可见）**：egui 对“焦点控件之外的指针按下”一律 surrender 焦点（context.rs）——点菜单项即丢焦点；且 egui 只在有焦点时绘制选区高亮，全选因此“看不见效果”。修复：四个菜单动作（复制/剪切/粘贴/全选）执行后 `request_focus` 交还焦点。
- **bug 6（全选后剪切不生效）**：全选动作丢焦点后，焦点迁移帧的 IME 守卫（builder.rs：`gained_focus || lost_focus` 时把选区收成单点，仅对用过 IME 的输入框生效）会抹除选区，随后右键菜单里剪切为禁用。修复：全选时把选区写入 pending 槽，焦点稳定后由 `text_edit_menu` 每帧前置逻辑重放（主按下清除）。harness 实证：菜单流程（ surrender→夺回→迁移帧）全选存活、全选后剪切清空缓冲区、部分剪切拼接、粘贴保焦点插入。
- **bug 7（选区高亮不明显）**：底色 rgb(240,245,255)（近白）→ rgb(178,208,247)，描边不变。
- **harness 基建修正**：合成点击的帧步长必须 < egui `max_click_duration`（0.8s），此前 1s 步长导致释放不算点击（探针实验实锤）。
