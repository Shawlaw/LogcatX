# v0.4.0 计划

## 变更内容

### 1. GitHub 项目入口按钮

**需求**：主界面增加跳转到项目地址 `https://github.com/Shawlaw/LogcatX` 的按钮，位置要自然、好看，不像临时塞进去的调试入口。

**方案**：
- 放在主界面顶部摘要区，与标题/版本信息同区域展示
- 视觉上做成轻量 secondary button 或链接风格按钮
- 点击后调用系统默认浏览器打开 GitHub 项目页

**改动**：

#### `src/app.rs`
- 调整顶部摘要区布局
- 在不破坏现有统计卡片的前提下加入 `GitHub` / `项目主页` 入口按钮
- 处理点击事件与错误反馈

#### i18n 文案
- 补齐中英文按钮文案和状态提示

### 2. 更新应用图标

**需求**：替换当前应用图标，让版本观感更完整。

**改动**：

#### `icons/`
- 替换窗口图标使用的 PNG
- 替换 Windows 资源打包使用的 `icon.ico`

#### `src/main.rs`
- 确认运行时窗口图标使用新的资源

#### `build.rs`
- 确认 Windows EXE 资源图标继续正确嵌入

### 3. USB 设备插拔自动刷新

**需求**：USB 设备插入或移除后，设备列表自动刷新，不再依赖手动点击“刷新设备”。

**方案**：
- 后台线程定时执行 `adb devices`
- 比较设备快照（`serial + state`）
- 只有检测到变化时才触发 UI 刷新和状态提示

**改动**：

#### `src/app.rs`
- 增加后台设备快照轮询
- 在设备变化时自动发送刷新事件
- 避免高频轮询导致无意义刷新

#### `src/adb.rs`
- 复用现有设备枚举逻辑
- 如有必要，补充更明确的错误输出

### 4. 设备别名与优先展示

**需求**：支持为设备设置别名；设备列表中优先显示别名，没有别名时回退到原始序列号。

**方案**：
- 设备身份主键仍然使用 `serial`
- 展示层新增“显示名”概念：优先别名，回退序列号
- 排序上优先展示有别名或置顶设备

**改动**：

#### `src/config.rs`
- 新增设备别名持久化字段

#### `src/models.rs`
- 扩展设备模型，支持展示名和排序辅助信息

#### `src/app.rs`
- 增加编辑别名入口
- 列表、详情区、状态提示统一显示别名优先的设备名称

### 5. 别名持久化 + 日志目录按别名存放

**需求**：
- 别名写入配置，重启后仍保留
- 设备日志文件的上级目录改为按别名存放
- 修改别名时，已有日志目录要跟着重命名

**方案**：
- `config.json` 新增 `device_aliases`
- 目录名优先使用清洗后的别名，回退到清洗后的序列号
- 别名修改时，若旧目录存在且新目录不存在，则执行目录重命名

**改动**：

#### `src/config.rs`
- 新增 `device_aliases` 配置项
- 保证旧配置可平滑兼容

#### `src/fs_utils.rs`
- 日志目录规则改为“别名优先，序列号回退”
- 提供目录重命名和冲突检查能力

#### `src/app.rs`
- 修改别名后同步刷新设备展示
- 处理目录重命名结果和错误提示

**风险点**：
- 设备正在采集中时改别名，是否允许立即迁移目录，需要实现时明确策略
- 若目标别名目录已存在，需要避免覆盖已有日志

### 6. IP+端口快捷连接设备 + 最近连接记录

**需求**：
- 支持直接输入 `IP:端口` 连接设备
- 保存最近成功使用过的连接记录，方便一键重连

**方案**：
- 在主界面工具栏增加“连接设备”入口
- 弹出输入框或小窗输入 `IP:端口`
- 调用 `adb connect`
- 成功后写入最近连接记录，失败时给出清晰错误

**改动**：

#### `src/adb.rs`
- 新增 `adb connect` 能力
- 解析连接结果与错误输出

#### `src/config.rs`
- 新增 `recent_connections`
- 限制保存条数，避免配置无限增长

#### `src/app.rs`
- 增加连接入口、最近记录列表和一键重连交互

### 7. 设备置顶功能

**需求**：允许用户将常用设备固定在列表前面。

**方案**：
- 使用 `serial` 作为置顶标识
- 排序规则建议为：置顶优先 -> 有别名优先 -> 名称排序

**改动**：

#### `src/config.rs`
- 新增 `pinned_devices`

#### `src/app.rs`
- 增加置顶/取消置顶操作
- 调整设备列表排序逻辑

### 8. 设备状态提示优化

**需求**：当前 `device / offline / unauthorized / disconnected` 等状态表达偏原始，需要更易懂。

**方案**：
- 保留底层原始状态值
- UI 层给出更友好的显示文案和颜色区分
- 在无法开始采集或连接异常时提供更明确提示

**改动**：

#### `src/app.rs`
- 优化设备状态展示
- 优化启动采集失败、设备不可用等场景的状态提示

#### i18n 文案
- 补齐中英文设备状态文案

## 今晚工作量判断

这版范围 **可以作为今晚目标**，但整体偏满，主要风险集中在：

1. **别名持久化 + 日志目录迁移 + 改名重命名目录**：这是最高耦合的一块
2. **IP+端口快捷连接 + 最近连接记录**：需要补完整交互和配置存储
3. **USB 自动刷新**：需要做稳定的后台检测，而不是简单频繁重刷

**建议节奏**：

1. 先完成低风险项：
   - GitHub 按钮
   - 图标更新
   - 设备状态提示优化
2. 再完成中等复杂度项：
   - USB 自动刷新
   - IP+端口连接
   - 最近连接记录
   - 设备置顶
3. 最后攻坚高耦合项：
   - 设备别名
   - 别名持久化
   - 日志目录迁移
   - 改名重命名目录

如果最后一块进度不理想，优先保证：
- 别名展示与持久化先上线
- 日志目录重命名必要时顺延到后续小版本

## 不做的事

- 不在 v0.4.0 中引入自动更新
- 不做多设备批量操作
- 不做更大范围的实时 Logcat 工作台重构
