# LogcatX 待办事项 & 发布方向

## 当前发布目标

- 平台：Windows
- 形式：绿色版 zip + 单 exe
- 配置：优先 exe 同目录，其次 AppData
- 版本里程碑：`v0.2.0`

---

## 待实现事项

### 1. Windows 启动黑框

**现状**：当前启动时仍会弹出控制台黑框，不符合桌面 GUI 工具的发布体验。

**思路**：
- 默认使用 Windows GUI subsystem
- 保留 `console` feature / `--console` 调试模式
- 参考 `clipImg` 的 `windows_subsystem = "windows"` 做法

### 2. 应用运行日志缺失

**现状**：只有设备采集日志，没有应用自身的运行日志，启动失败和运行异常难以定位。

**思路**：
- 增加 `.logcatx.log`
- 支持文件日志、可选控制台日志、日志轮转
- 增加 panic hook

### 3. 便携配置模式

**现状**：当前配置只走 AppData 风格路径，不适合绿色版 zip 使用。

**思路**：
- 优先读取 exe 同目录 `config.json`
- 首次运行默认写回 exe 同目录
- 如果 exe 目录不可写，再回退 AppData

### 4. EXE 图标与版本信息

**现状**：没有图标，没有 Windows 文件属性版本信息。

**思路**：
- 新增 `build.rs`
- 新增 `icons/icon.ico`
- 嵌入版本、产品名、描述等资源

### 5. 首启引导过于原型化

**现状**：首次启动虽然能配置，但解释不足，用户不清楚运行日志与设备日志的区别。

**思路**：
- 补充文案说明
- 强化路径校验反馈
- 增加打开日志目录 / 打开应用日志 / 打开配置目录入口

### 6. README / CHANGELOG / config.example 缺失

**现状**：项目还没有面向外部用户的正式文档。

**思路**：
- README 用于介绍和使用说明
- CHANGELOG 用于版本变更说明
- config.example.json 用于发布包参考

## 设备管理与连接体验（待规划）

### 1. 设备别名与优先展示

**目标**：
- 支持为设备设置自定义别名
- 列表中优先显示别名，没有别名时回退到设备序列号或原始标识

### 2. USB 设备插拔自动刷新

**目标**：
- 检测 USB 设备插入/移除事件
- 自动刷新设备列表，减少手动刷新操作

### 3. IP+端口快捷连接设备

**目标**：
- 提供直接输入 `IP:端口` 的快捷连接方式
- 展示连接结果与常见错误提示

### 4. 设备收藏/置顶

**目标**：
- 支持收藏常用设备
- 让收藏或置顶设备稳定显示在列表前部

### 5. 最近连接记录

**目标**：
- 保存最近使用过的 `IP:端口`
- 支持一键重连或快速选择

### 6. 设备状态提示优化

**目标**：
- 更明确区分 `online`、`offline`、`unauthorized` 等状态
- 为异常状态提供更易理解的说明

### 7. 网络设备自动重连

**目标**：
- Wi-Fi / TCP 设备断开后尝试自动重连
- 在界面中反馈重连状态与结果

### 8. 设备分组与筛选

**目标**：
- 支持按 USB、Wi-Fi、模拟器等来源分组
- 支持按品牌、型号、Android 版本等信息筛选

### 9. 别名持久化

**目标**：
- 基于稳定标识保存设备别名
- 避免设备重插、重启后别名丢失

### 10. 多设备批量操作

**目标**：
- 支持多选设备
- 批量执行连接、断开、日志相关操作

### 11. 连接诊断

**目标**：
- 在连接失败时给出更明确原因
- 覆盖网络不可达、ADB 未开启、端口异常等常见问题
