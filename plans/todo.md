# adb-logcat-collector 待办事项 & 发布方向

## 当前发布目标

- 平台：Windows
- 形式：绿色版 zip + 单 exe
- 配置：优先 exe 同目录，其次 AppData
- 版本里程碑：`v0.2.0`

---

## 待实现事项

### 1. Windows 启动黑框

**现状**：当前启动时仍会弹出控制台黑框，不符合桌面 GUI 工具的发布体验。

**思路**：
- 默认使用 Windows GUI subsystem
- 保留 `console` feature / `--console` 调试模式
- 参考 `clipImg` 的 `windows_subsystem = "windows"` 做法

### 2. 应用运行日志缺失

**现状**：只有设备采集日志，没有应用自身的运行日志，启动失败和运行异常难以定位。

**思路**：
- 增加 `.adb-logcat-collector.log`
- 支持文件日志、可选控制台日志、日志轮转
- 增加 panic hook

### 3. 便携配置模式

**现状**：当前配置只走 AppData 风格路径，不适合绿色版 zip 使用。

**思路**：
- 优先读取 exe 同目录 `config.json`
- 首次运行默认写回 exe 同目录
- 如果 exe 目录不可写，再回退 AppData

### 4. EXE 图标与版本信息

**现状**：没有图标，没有 Windows 文件属性版本信息。

**思路**：
- 新增 `build.rs`
- 新增 `icons/icon.ico`
- 嵌入版本、产品名、描述等资源

### 5. 首启引导过于原型化

**现状**：首次启动虽然能配置，但解释不足，用户不清楚运行日志与设备日志的区别。

**思路**：
- 补充文案说明
- 强化路径校验反馈
- 增加打开日志目录 / 打开应用日志 / 打开配置目录入口

### 6. README / CHANGELOG / config.example 缺失

**现状**：项目还没有面向外部用户的正式文档。

**思路**：
- README 用于介绍和使用说明
- CHANGELOG 用于版本变更说明
- config.example.json 用于发布包参考
