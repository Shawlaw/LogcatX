## [0.9.0] - 2026-09-28

### 新增
- 设备文件浏览器（设备文件页）：浏览设备目录，支持面包屑与路径跳转、名称/大小/修改时间排序、多选、快捷路径（/sdcard、Download、DCIM、Pictures、Documents、/data/local/tmp）与目录收藏；新建文件夹、重命名、移动、删除（批量删除一次确认并明确显示数量）；拖入文件即上传到当前目录，拖入 APK 可选择安装或上传；双击文件即下载；run-as 浏览 debuggable 应用数据（/data/data），页面明确标注为“应用数据（run-as）”
- 统一传输队列：文件上传/下载入队执行，显示进度与已传字节，支持单任务取消、全部取消、失败重试与清除已完成；完成后显示起止时间，并提供“打开文件 / 打开所在目录 / 跳转到目的目录”快捷操作（执行前核验目标存在）；USB 与无线行为一致，多批拖入互不阻塞
- 所有输入框支持右键菜单（剪切/复制/粘贴/全选，中文等多字节文本按字符边界精确处理，选中与焦点行为符合 Windows 习惯）；文件列表的文件名右键可复制文件名或完整路径

### 增强
- ADB 稳定性：所有 adb 调用具备超时、取消、输出上限与子进程回收，单条命令挂死不再锁死界面；无线配对/连接与普通调用共用同一套进程管理；各设备的操作相互独立，互不阻塞
- 设备列表更稳：设备静态信息（厂商/型号/系统版本/序列号）跨轮询缓存；发现结果带代际保护，旧状态不再被覆盖；同一设备的 USB 与无线连接合并为一行（USB 优先），无线轮换端口按主机归并，握手中的网络端点不再显示为“未知状态”幽灵行
- 更新体验：签名更新候选持久化，重启后无需重新联网即可继续下载；更新弹窗直接内嵌展示更新说明（加载失败不影响下载安装，可重试或跳转 Release 页）；自动检查按结果退避（成功后 24 小时、网络失败 3~6 小时、清单异常 24 小时）；更新应用确认（ACK）改为健康启动（首帧渲染）后发送，启动失败自动回滚
- 诊断信息带构建提交号：设置页与更新弹窗显示 v0.9.0 (commit)，命令行 `LogcatX.exe --version` 同步支持；主界面保持只显示版本号

### 修复
- 日志清理不再跟随符号链接/junction，任何情况下都不会删除日志根目录之外的文件；清理进行中新启动的日志采集受实时保护，不会被误删
- 配置与更新状态改为原子写入，崩溃中断不再产生损坏文件；0.8 配置无缝迁移至 0.9.0
- Windows 数字版本资源（FILEVERSION）与语义版本一致（0.9.0.0），不再使用构建日期
